What these numbers mean

This is a snapshot of the website’s HTML, CSS, and JavaScript at the completed Lab 5 commit, before adding this page. It was generated with elocuent and Git blame.

Only commits that still contribute lines to that snapshot appear here. Dot size counts surviving lines, not every line ever added or deleted, and is not a measure of time spent working. Data files, images, Python, and installed packages are outside this analysis. Dates and times use your browser’s local time zone: .
